React Redux (Part 2)

Description
This project focuses on optimizing Redux Toolkit applications for better performance. You'll learn to identify and fix React performance issues, implement memoized Redux selectors, manage component re-renders, and optimize state management patterns using advanced Redux Toolkit features.

Learning Objectives
At the end of this project, you are expected to be able to explain to anyone, without the help of Google:

Understanding React performance issues
Memoized Redux selectors
Requirements
All your files will be interpreted/compiled on Ubuntu 20.04 LTS using node 20.x.x and npm 10.x.x
Allowed editors: vi, vim, emacs, Visual Studio Code
All your files should end with a new line
A README.md file, at the root of the project's folder and each task's folder, is mandatory
Install Jest globally: npm install -g jest version 29.7.0
Mandatory Tasks
Task 0. Now You See ME (The easy way)
Task 1. Loading state
Task 2. Implement Course Selection
Task 3. Memoized selector
