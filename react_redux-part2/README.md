# 🚀 React Redux (Part 2)

## 📌 Description
This project focuses on **optimizing Redux Toolkit applications** for better performance.

You will learn to:
- Identify and fix React performance issues  
- Implement memoized Redux selectors  
- Manage unnecessary component re-renders  
- Optimize state management using advanced Redux Toolkit features  

---

## 🎯 Learning Objectives
At the end of this project, you are expected to be able to explain to anyone, without the help of Google:

- Understanding React performance issues  
- Memoized Redux selectors
